# Product Vision and MVP

**Vision:** To deliver a modern, automated, cloud-ready Library Management Platform that reduces manual administrative work, streamlines circulation, and provides an intuitive digital catalog for academic communities.

## MVP features
1. User login and role-based access for Admin, Librarian, Student, and Faculty.
2. Book search and availability status.
3. Basic issue and return transactions.
4. Overdue fine calculation.
5. Basic administrative reports.

AI recommendations and third-party payment gateways are deferred.
