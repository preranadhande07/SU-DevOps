# IBM Design Thinking and Observe–Reflect–Make Loop

## Pillars
- Focus on user outcomes, not only technical features.
- Restless reinvention through continuous feedback and improvement.
- Diverse, empowered cross-functional teams.

## Loop
- **Observe:** Study user interactions, logs, feedback, and delays.
- **Reflect:** Analyze findings and set priorities.
- **Make:** Prototype, implement, test, and deploy an improvement.

Example: if users cannot identify available books, observe search behavior, reflect on the unclear status label, then make and test a clearer availability indicator. This example is illustrative.
