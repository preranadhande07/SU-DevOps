# Library Management Platform
## Unit 1: Product Engineering & Design Thinking

This repository contains the planning and engineering scaffold for an academic library platform. The MVP includes role-based login, book search and availability, issue/return transactions, fine calculation, and basic reports.

## Structure
- `docs/`: business problem, product vision, Design Thinking, personas, requirements, architecture, roadmap.
- `app/`: planned application modules and database schema concept.
- `docker/`, `kubernetes/`, `terraform/`, `ansible/`, `monitoring/`: deployment and operations planning.
- `.github/workflows/`: basic repository-document checks.

**Note:** This is an academic scaffold, not a production-ready system. Do not commit credentials or real student/library data.
